# Security reporting

Use GitHub private vulnerability reporting when enabled in this repository. If it is unavailable, open an issue asking a maintainer for a private contact channel and omit vulnerability details. Share the minimal reproduction, affected revision and impact privately after contact. Use synthetic records and redact credentials, tokens and internal addresses. Coordinate disclosure timing with the maintainer.

This repository contains the browser-only demonstration. Report findings about the separately hosted authenticated application privately to its maintainers. VIGIL is an educational prototype with fictional records.
